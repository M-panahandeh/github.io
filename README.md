# Mahsa Panahandeh Personal Website

This folder contains the complete static website. It can be published directly with GitHub Pages.

## Publish at m-panahandeh.github.io

1. Sign in to GitHub.
2. Create a new public repository named exactly `M-panahandeh.github.io`.
3. Upload every file and folder from this package to the repository root. The `index.html` file must be at the top level, not inside another folder.
4. Open the repository's **Settings**, select **Pages**, and under **Build and deployment** choose **Deploy from a branch**.
5. Select the `main` branch and the `/(root)` folder, then click **Save**.
6. After GitHub finishes publishing, visit https://m-panahandeh.github.io.

## Update the website later

Edit `index.html` for text and links, edit `style.css` for appearance, and replace image files while keeping their filenames unchanged. Commit the changes to the `main` branch. GitHub Pages will republish automatically.
